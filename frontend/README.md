# Movie & Anime Watchlist — Frontend

React (Vite) client for the Movie & Anime Watchlist app.

See the [project README](../README.md) for full setup instructions
(backend + frontend) and a description of the features.

Quick start:

```bash
npm install
npm run dev
```

Runs at http://localhost:3000 and expects the Django API at
http://127.0.0.1:8000 (see `../backend`).
